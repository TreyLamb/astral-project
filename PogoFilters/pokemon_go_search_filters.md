# Pokémon GO Search Filters (Pokémon Inventory)

This list covers common search filters for your Pokémon inventory in Pokémon GO. Use these to quickly sort and manage your collection.

## Basic Filters
| Filter | Description |
| :--- | :--- |
| `[name]` | Search by name, species, or nickname |
| `[type]` | Search by type (e.g., `Fire`, `Water`) |
| `#[number]` | Search by Pokédex number |
| `! [filter]` | Negates the filter (e.g., `!Fire` shows all non-Fire types) |
| `&` | "AND" operator (e.g., `Fire&Shiny`) |
| `,` | "OR" operator (e.g., `Fire,Water`) |

## Age & Date
| Filter | Description |
| :--- | :--- |
| `age#` | Caught exactly # days ago |
| `age-#` | Caught in the last # days |
| `age#-#` | Caught between # and # days ago |
| `age#-` | Caught # or more days ago |
| `year#` | Caught in a specific year (e.g., `year2022`) |

## Combat & IVs
| Filter | Description |
| :--- | :--- |
| `0*`, `1*`, `2*`, `3*`, `4*` | Search by appraisal rating (4* is perfect IV) |
| `cp#` | Search by exact CP |
| `cp-#` | CP up to # |
| `cp#-#` | CP range |
| `hp#` | Search by exact HP |
| `hp-#` | HP up to # |
| `hp#-#` | HP range |
| `attack#`, `defense#`, `stamina#` | Search by individual IV stat |

## Status & Attributes
| Filter | Description |
| :--- | :--- |
| `shiny` | Shiny Pokémon |
| `legendary` | Legendary Pokémon |
| `mythical` | Mythical Pokémon |
| `ultra beast` | Ultra Beasts |
| `shadow` | Shadow Pokémon |
| `purified` | Purified Pokémon |
| `lucky` | Lucky Pokémon |
| `mega` | Pokémon capable of Mega Evolution |
| `costume` | Pokémon wearing a costume |
| `baby` | Baby Pokémon |
| `evolve` | Pokémon you have enough candy to evolve |
| `favorite` | Your favorited Pokémon |
| `item` | Pokémon that require an item to evolve |
| `gender:male` / `gender:female` | Filter by gender |

## Moves
| Filter | Description |
| :--- | :--- |
| `@move` | Pokémon with a specific move |
| `@1move` / `@2move` / `@3move` | Fast move / Charged move / Legacy move |
| `@special` | Pokémon with Community Day or exclusive moves |

## Distance (Trade)
| Filter | Description |
| :--- | :--- |
| `distance#` | Caught exactly # km away |
| `distance-#` | Caught within # km away |
| `distance#-#` | Caught between # and # km away |
