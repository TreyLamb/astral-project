Digital Infrastructure & Logistics
1. The "Zero-Inbox" LLM Gatekeeper
The Blueprint: A background script scans your inbox every 10 minutes. It passes incoming non-personal emails to a free LLM API, categorizes them, extracts action items, and archives the rest.

The Stack: Google Apps Script + Gemini API + Gmail Labels.

Mechanics: GAS fetches unread emails, sends the text payload to Gemini via a free API fetch, receives a JSON category (Newsletter, Receipt, Action Required), applies the corresponding Gmail label, and archives everything except Action Required.

2. Auto-Expiring Temporary Downloads
The Blueprint: Your local download folder remains completely empty. Files are automatically sorted by extension, and temporary files (like downloaded PDFs you only need once) self-destruct after 48 hours.

The Stack: Python + Windows Task Scheduler / Mac Launchd.

Mechanics: A 15-line local Python script runs every night. It checks the metadata creation date of files in your ~/Downloads folder. Images move to ~/Pictures, .dmg/.exe files are deleted after 2 days, and documents are pushed to your cloud drive.

3. Voice-to-Structured-Task Ambient Capture
The Blueprint: You speak a chaotic, unstructured thought into your watch or phone while walking. Without you opening a single app, it is perfectly formatted into a project task, assigned a priority, and dropped into your task manager.

The Stack: Apple Shortcuts + Whisper API / Gemini API + Notion (or Todoist) API.

Mechanics: A 1-click Apple Shortcut records audio, sends the audio transcript to the LLM with a system prompt ("Extract task name, due date, and project from this brain dump"), and uses a Webhook to POST the structured JSON straight into your Notion workspace.

4. The Smart Receipt & Document Funnel
The Blueprint: You take a photo of a physical receipt or document. The system automatically performs OCR, renames the file using a strict schema (YYYY-MM-DD_Vendor_Amount.pdf), and files it into a specific cloud folder.

The Stack: Google Drive App + Google Apps Script.

Mechanics: Snap the photo directly inside the free Google Drive widget into a folder called "Inbox". A Google Apps Script watches this folder, uses Google's built-in DocumentAI/OCR to read the text, runs a regex to pull the date and total amount, renames the file, and moves it to a "Tax 2026" folder.

5. Automated SaaS Free-Tier Rotation & Tracker
The Blueprint: Never get caught by a "surprise charge" after signing up for a free trial.

The Stack: Apple Shortcuts + Make.com + Google Sheets.

Mechanics: Set up a Shortcut that generates a random temporary email alias (using free services like Cloudflare Email Routing or DuckDuckGo Email Protection) when you sign up for a trial. The shortcut automatically logs the date, service name, and trial length into a Google Sheet, which sends you a calendar notification 48 hours before the trial ends.

6. Subreddit/RSS to Personalized Daily Briefing
The Blueprint: Stop doomscrolling. A background worker compiles top industry news, filtering out fluff, clickbait, and duplicate topics, giving you a 3-bullet point summary of your favorite feeds at 8:00 AM.

The Stack: GitHub Actions + Python + Free LLM API + Email.

Mechanics: A free GitHub Actions workflow runs on a cron job daily. It scrapes the RSS feeds of your top sites or specific subreddits, passes the aggregated text to an LLM to "Synthesize the top 3 actual macro developments," and emails you a clean, plain-text summary.

7. The Phantom Desktop Cleaner
The Blueprint: Your desktop never accumulates clutter. Any file left on the desktop for more than 4 hours is silently archived into a historical calendar folder system.

The Stack: Local Shell Script (Bash/PowerShell) + Cron.

Mechanics: A script runs in the background checking the desktop folder. If a file's age exceeds 4 hours, it creates a folder structure like ~/Archive/2026/July/ and moves the file there. You retain a searchable history without the visual anxiety.

8. Clipboard History AI Assistant
The Blueprint: Hit a single hotkey to instantly clean, format, or extract data from whatever text is currently copied to your clipboard.

The Stack: Mac Automator / Windows PowerToys Run + Python Script + Free LLM API.

Mechanics: Highlight messy data (like an unformatted list of addresses or a chaotic email thread), hit your hotkey. The script grabs the clipboard contents, passes it to a local/free LLM to clean up or convert to JSON/Markdown, and overwrites your clipboard with the perfected output instantly.

9. Automatically De-Duplicating Cloud Backups
The Blueprint: Merging multiple old cloud drives or hard drives without wasting days looking for duplicates.

The Stack: Open-source Rclone tool (Free).

Mechanics: Run a local terminal command via Rclone that compares file hashes (not just names) across Google Drive, OneDrive, or local drives. It deletes precise duplicates silently in the background, preserving only the unique files.

10. Automatic Browser Tab Self-Destruct & Archive
The Blueprint: Prevent browser slowdowns and mental clutter from having 80 open tabs.

The Stack: Free browser extensions like Tabox or Session Buddy + Simple JavaScript.

Mechanics: Configure an automation that auto-closes tabs that haven't been viewed in 24 hours, but writes their URLs and page titles to a searchable Markdown log file in your cloud drive so you never "lose" a page.

11. Low-Battery Device Inter-Notifier
The Blueprint: If your tablet, secondary laptop, or phone hits less than 15% battery in another room, your primary device alerts you.

The Stack: IFTTT (Free tier) / Apple Shortcuts.

Mechanics: A native automation trigger on Device A runs when battery drops below 15%, sending a silent webhook to Device B that triggers a high-priority push notification.
