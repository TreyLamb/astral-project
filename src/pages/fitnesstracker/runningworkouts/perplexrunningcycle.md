# 11-Day / Flexible Microcycle Draft

## Principles
- Running is the priority.
- Lifting does not replace runs.
- Upper-body lifting can happen on run days.
- Leg day is both a lifting day and a speed-like stressor.
- Back day is a protected training node and needs mileage-only cushioning before, during, and after.
- Speed days must be separated enough to preserve quality.
- One true rest day should exist somewhere in the cycle.

## Preferred weekly logic
- 2 true speed run days.
- 1 leg day that functions as a third speed stimulus.
- 1 threshold day.
- 1 longer run or medium-long run.
- Multiple easy/recovery mileage days.
- 1 true rest day.

## Example 11-Day Flow
| Day | Focus | Notes |
|---|---|---|
| Day 1 | Speed Day 1 | Track workout, morning run optional, upper lift later if desired. |
| Day 2 | Easy run + upper lift | No heavy leg stress. |
| Day 3 | Easy run | Mileage only; avoid speed. |
| Day 4 | Back day + easy run | Protected day: day before, day of, and day after should be mileage-only. |
| Day 5 | Easy run | Keep it light. |
| Day 6 | Speed Day 2 | Track workout or interval session. |
| Day 7 | Easy/recovery run | Very light, protect next day. |
| Day 8 | Leg day + third speed stimulus | Can include sled drags, carries, short controlled power work. Optional easy morning run only. |
| Day 9 | Easy run | Mileage only; no speed. |
| Day 10 | Rest day | True rest or very light walking only. |
| Day 11 | Longest run / medium-long run | Easy aerobic focus, not a race. |

## Protected nodes
- Back day: day before, day of, and day after remain mileage-only.
- Leg day: the next day should be easy.
- Speed day: should not be followed immediately by another hard speed session.

## Quality sessions
- Speed day 1: track intervals, strides, or controlled fast repeats.
- Speed day 2: slightly different stimulus than day 1.
- Leg-day speed: strength-speed work, sleds, carries, low-volume explosiveness.
- Threshold day: tempo or cruise intervals.
- Long run: steady aerobic base.

## Reassessment
- Re-test every 4 to 6 weeks.
- Adjust based on fatigue, pace response, and recovery.
- If paces stall or soreness accumulates, reduce volume before increasing intensity.
