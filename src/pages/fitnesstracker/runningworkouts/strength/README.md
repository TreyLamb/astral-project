## Why this folder exists

The PFRA is four scored components. The running docs cover exactly one of them (cardio, 50 pts).
Push-ups (15 pts) and core (15 pts) are Trey's own programming, and were previously invisible to
the plan — which meant cycle tables showed a running day next to nothing, even on days he was
doing real strength work.

## How it's used

When a cycle is built, `pushups-situps.md` is read and the strength work is rendered **alongside**
the running days so a cycle table shows the whole week, not just the runs.

## Rules for whoever builds the next cycle

1. **Read `pushups-situps.md` before writing a cycle table.** If it has content, render it.
2. **Do not invent, "improve", or rebalance the strength programming.** If something in it looks
   like it conflicts with the running plan — a heavy push-up day the morning of a threshold
   session, say — **raise it as a question, don't silently fix it.**
3. **Respect the existing bench/back windows** from the retired pushup work: avoid loading
   push-ups the day before, the day of, or the two days after **Lift A** (chest), and the day
   before/of/after **Lift C** (back). These are guidelines, not `cycle.md` hard rules — Trey
   overrides them freely.
4. Targets live in `../Guidelines_AF`: push-ups **56**, sit-ups **52** (male, 35–39).
5. If the file is still a blank template, render nothing and say so — never fill it in with a
   plausible-looking guess.
