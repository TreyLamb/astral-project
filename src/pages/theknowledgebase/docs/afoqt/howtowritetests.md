Build a test blueprint
Before drafting, make a small table like this:

Topic / skill	What the student must do	Cognitive level	Target questions	Difficulty
Circuits	Calculate voltage, current, or resistance	Apply	4	Moderate
Geometry	Select and use a volume formula	Apply	5	Moderate
Levers	Predict how force changes with position	Understand / apply	3	Easy–moderate
Use three levels:

Recall: Define, identify, name, recognize.

Understanding: Explain, compare, predict.

Application: Calculate, diagnose, select a method in a new situation.

A question is “appropriate” when it matches a specific intended skill and level—not merely when it looks like the original.

Write questions reliably
For each source question, use this sequence:

Write the skill statement: “Student can calculate resistance when voltage and current are known.”

Choose the level: direct substitution is easier; deciding which formula or value is needed is harder.

Draft the correct answer first.

Add wrong answers based on real mistakes: reversing a formula, using the wrong unit, forgetting a conversion, or confusing related concepts.

Check that there is exactly one best answer and that wording does not accidentally hint at it.

Good wrong choices are plausible to someone with a specific misconception. They should not be silly, obviously longer, grammatically mismatched, or “all of the above.” Clear stems should present one problem and avoid irrelevant detail.

Control difficulty
Difficulty is not just “hard numbers.” It comes from how many decisions and steps are required:

Easy: Same form as practice; one obvious fact or formula.

Moderate: Must choose the concept or formula, then execute it.

Hard: Requires multiple linked ideas, interpreting a diagram/data set, or rejecting tempting but incorrect approaches.

After people take the test, measure each item’s difficulty as the percent who answered correctly. Also check discrimination: a strong question is answered correctly more often by high overall scorers than low overall scorers; questions everyone gets right or wrong usually discriminate poorly.

A practical rule
For a typical practice test, aim mostly for moderate questions, include a smaller number of easy confidence-checks, and reserve only a few hard items for genuine higher-level reasoning. Keep an “item bank” spreadsheet with columns for skill, level, source-question family, correct answer, misconception behind each distractor, and results after testing it. This gives you the same feedback loop instructors use to improve exams over time.
