# Barron's screenshots — reference index

11 PNGs (`BarronsIndexScreenshots/`, opaque hashes, no page numbers in the filenames — identified
below by content). These are photos of two sections of *Military Flight Aptitude Tests* (Barron's,
4th Ed): the front-of-book **Contents** (3 pages) and the back-of-book **Index** (8 pages, A→Y).

**Not the same set PLAN.md mentions.** PLAN.md's "TREY'S BARRON'S SCREENSHOTS" note refers to a
different, earlier batch of diagram-page captures (Table Reading grid / IC dials / Block Counting
piles) that isn't part of this upload. This set is new and purpose-built as a **page finder**: it
lets you go straight to the right book page for a topic without re-flipping the whole book.

⚠️ **Reference only — do NOT ship these into the app, and do not paste index text into the repo
verbatim.** Same copyright rule as `RESEARCH-INDEX.md` and `RESEARCH.md`: this is a paid book. A
page number and a topic word are fine to note; author lessons and questions from your own
understanding of the topic, never from the book's wording. See `RESEARCH.md`'s copyright note.

⚠️ **Minor capture artifact:** every image has a thin dark strip cropped in at the very top
(browser/scroll-chrome, ~5-10px) — not book content, ignore it.

To convert any book page number below to the corresponding PDF page in the scanned file, use
`PLAN.md`'s **BARRON'S PAGE MAP**: `PDF page = book page + 9`.
