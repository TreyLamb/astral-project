# AFROTC Class — Samples of Behavior (SOB) Objectives

Source list provided by cadet, 2026-09-03. This is the authoritative scope for the
crash-course study guide in this folder.

## Required Preparation (from the syllabus)

> Refer to Appendix A for preparation material. **Cadets should be ready to recite
> from memory the chain of command, customs and courtesies, and the DAF/Joint Force
> grade structure** from their study.

**Recite-from-memory priority block** — these three drive the graded recitation and
lead the study guide:

1. Chain of command (SOB 2.1, 2.2)
2. Customs and courtesies (SOB 4.1, 4.4, 4.6, 4.7)
3. DAF / Joint Force grade structure (SOB 1.1, 1.2, 1.3)

Everything else below is performance-graded (P) or secondary knowledge.

## Column key

Verified against **AFROTCI 36-2011 Vol 1**, *Cadet's Guide to Leadership Laboratory
(LLAB) Curriculum* (memo 3 Sep 2024). The four trailing columns are **cadet
classification levels**, not code categories — each cell states the proficiency
required of that class of cadet for that objective.

| Column | Meaning | Typical class year |
| --- | --- | --- |
| SOB # | Sample of Behavior number | — |
| BC | **Basic Cadet** — GMC cadet not yet in the POC-selection year | AS100 |
| BCL | **Basic Cadet Leader** — GMC cadet in the POC-selection year | AS200 / AS250 / AS500 |
| ICL | **Intermediate Cadet Leader** — just entered the POC | AS300 |
| SCL | **Senior Cadet Leader** — commissioning the upcoming year | AS400 |

Proficiency codes: `Ka` = knowledge, recall/identify. `Kb` = knowledge,
comprehend/summarize. `P1` / `P2` / `P3` = performance (imitation → repetition →
precision).

⚠️ **Column alignment is unrecoverable from the pasted text.** The source table's
spacing was lost, so which class each code sits under cannot be reconstructed here —
e.g. 4.2's `P1 P2 P3` is three values across four columns. The objective list below
records the codes in the order given. **Read your own syllabus table for the column
your class year actually falls in.**

## Scope note on 7.2

AFROTCI 36-2011 Vol 1 defines **SOB 7.2 as stationary movements only** — Attention,
Parade Rest, Right/Left Face, About Face, Present/Order Arms — and states the lesson
"is intended to be instructed while individuals or flights are stationary rather than
while marching." **Marching movements sit under SOB 7.3** ("Demonstrate basic drill of
the flight"), which is not on the list above.

The study guide covers marching anyway, since it is the same practical block and is
likely to come up — but if the grading sheet is strict about SOB boundaries, marching
is 7.3, not 7.2.
