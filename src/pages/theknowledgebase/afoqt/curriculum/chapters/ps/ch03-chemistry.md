# States of matter, the periodic table, change, and acids and bases

Four areas: the states matter can take, how the periodic table is organized, physical versus
chemical change, and acids and bases.

---

## States of matter

| State | Shape | Volume |
|---|---|---|
| **Solid** | Definite | Definite |
| **Liquid** | Takes container's shape | Definite |
| **Gas** | Takes container's shape | Takes container's volume |
| **Plasma** | Ionized, gas-like — found in stars and lightning | — |

| Term | What it is |
|---|---|
| **Melting point** | Solid → liquid |
| **Boiling point** | Liquid → gas |
| **Sublimation** | Solid → gas, **skipping liquid entirely** |
| **Deposition** | Gas → solid, **skipping liquid entirely** |
| **Condensation** | Gas → liquid |

> ⚠ **Sublimation and deposition are the two changes that skip the liquid state.** Every other
> change on this list passes through it. That is the one fact that separates this pair from the rest.

---

## The periodic table's organization

| Term | What it is |
|---|---|
| **Chemical symbol** | The 1-2 letter abbreviation for an element |
| **Periodic table arrangement** | Elements ordered by **increasing atomic number** |
| **Metals / Nonmetals / Metalloids** | The three classes, sorted by conductivity |
| **Representative elements** | Main-group elements, groups 1-2 and 13-18 |
| **Transition metals** | Groups 3-12 |
| **Lanthanides / Actinides** | The two rows set apart at the bottom |
| **Periodic law** | Properties recur in a predictable pattern by atomic number |

> Mendeleev's original table ordered elements by atomic **mass** and left gaps that correctly
> predicted undiscovered elements. The modern table orders by atomic **number** instead — that
> correction is what the periodic law describes.

---

## Physical change vs. chemical change

| | Physical change | Chemical change |
|---|---|---|
| **Produces new matter?** | No | **Yes, always** |
| **Example** | Melting ice, cutting paper | Burning wood, rusting iron |

| Term | What it is |
|---|---|
| **Chemical reaction** | The process where substances transform into new substances |
| **Precipitate** | A solid that forms and separates out of a solution |
| **Exothermic** | Releases energy (heat) |
| **Endothermic** | Absorbs energy (heat) |
| **Catalyst** | Speeds up a reaction without being consumed |
| **Conservation of mass** | Total mass is the same before and after a reaction |

> ⚠ **"Always produces new matter" is the single test for a chemical change.** Rust is a chemical
> change because rust is a genuinely different substance from the iron, oxygen and water that made
> it — not because it looks different, and not because it can't be undone.

## Acids and bases

| | Acid | Base |
|---|---|---|
| **Releases** | Hydrogen ions | Hydroxide ions |
| **Litmus paper** | Blue → red | Red → blue |

| Term | What it is |
|---|---|
| **pH scale** | 0-14, with 7 neutral. Below 7 = acidic, above 7 = basic |
| **Neutralization** | Acid + base → water + salt |
| **Strong acid** | Ionizes almost completely in water (weak = only partly) |
| **Buffer solution** | Resists pH changes when a small amount of acid/base is added |
| **Hydronium ion** | Forms when a hydrogen ion attaches to a water molecule |

---

## Before you move on

- [ ] Sublimation and deposition are the two phase changes that skip the liquid state.
- [ ] The modern periodic table orders by atomic number, not atomic mass.
- [ ] A chemical change always produces new matter — that's the whole test.
- [ ] Acids release hydrogen ions and turn litmus red; bases release hydroxide ions and turn it blue.
