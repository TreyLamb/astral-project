# Aircraft type and the MDS system

**This chapter needs a clean 5/5 to test out of, and it is the highest-value twelve minutes in
the subtest.**

Here is why. Of the ten official Aviation Information questions in the Air Force's own Knowledge
Check, **two of them — twenty percent — test the designation letter system**:

> *"An aircraft with a Q designation means ___"* → remotely piloted
> *"A UH-60 is designated by which of the following ___"* → Utility and Helicopter

And almost **no commercial AFOQT guide covers it at all.** Skipping this chapter would be a
straight, silent blind spot: you would never know you were missing points.

---

## ⭐ It is a rule, not a list

The system is Mission-Design-Series. The critical insight is how to read it:

> **Read right to left. The LAST letter before the number is what the aircraft IS.**
> **Letters in front of it are what it has been MODIFIED to do.**

That single rule lets you decode a designation you have never seen.

- **UH-60** → **H** touches the number, so it *is* a **helicopter**. **U** in front modifies it:
  **utility**. A utility helicopter.
- **AC-130** → **C** touches the number, so it *is* a **cargo** aircraft. **A** in front: modified
  for **attack**. A gunship built on a transport.
- **KC-135** → a **cargo** airframe modified as a **tanker**.
- **RC-135** → the *same* airframe modified for **reconnaissance**.

## The mission letters

| Letter | Means |
|---|---|
| **A** | Attack |
| **B** | Bomber |
| **C** | Cargo / transport |
| **E** | Special **e**lectronic installation (airborne early warning) |
| **F** | Fighter |
| **H** | **H**elicopter (as basic type) *or* search and rescue (as modifier) |
| **K** | Tan**k**er — air-to-air refuelling |
| **M** | Multi-mission |
| **Q** | **Remotely piloted** / unmanned |
| **R** | Reconnaissance |
| **T** | Trainer |
| **U** | Utility |
| **V** | VTOL / STOL |
| **X** | Experimental |
| **Y** | Prototype / service test |

> **H is the one that does double duty**, and position decides which meaning applies. In **UH-60**
> the H touches the number, so it means *helicopter*. In **HH-60** the leading H is the modifier,
> making it a search-and-rescue helicopter.

**Q examples worth having:** MQ-9 Reaper (multi-mission, remotely piloted), RQ-4 Global Hawk
(reconnaissance, remotely piloted).

## Before you move on

- [ ] You read a designation **right to left**, and the letter touching the number is the type.
- [ ] You can decode **UH-60, AC-130, KC-135, RC-135, MQ-9, HH-60** without looking.
- [ ] **Q = remotely piloted.** This is one of ten official questions.
- [ ] The mission letters A, B, C, E, F, H, K, Q, R, T, U, V, X, Y.
- [ ] You can name what a C-130, C-17, C-5, B-52, B-2, A-10, E-3 and T-38 each are.
